# Reglas de negocio
- RN01: Un cliente puede realizar muchas compras en el local, pero un ticket
específico se asocia a un solo cliente.

- RN02: Un cajero procesa múltiples ventas en su turno, pero cada venta es
registrada por un único empleado.

- RN03: Un producto puede ser suministrado por uno o varios proveedores.
- RN04: Un cliente puede realizar una o muchas compras.

- RN05: Un proveedor puede suministrar uno o varios productos.

- RN06: Un cliente puede adquirir uno o varios productos.

- RN07: El sistema debe permitir a los empleados registrar ajustes de inventario
para sincronizar el stock del sistema con el disponible físicamente en el local.

- RN08: El sistema debe permitir el registro explicito de compradores para la
emisión de comprobantes formales nominativos.

- RN09: El sistema debe congelar el precio unitario del producto en el momento
exacto de la transacción, protegiendo el historial en caso de que la empresa
sufra inflación y cambie los precios en un futuro.

- RN10: No se puede dar finalizada ninguna venta sin especificar
obligatoriamente el método de pago utilizado por el cliente.

- RN11: Todo nuevo producto registrado en el catálogo debe estar asignado
obligatoriamente a una única categoría o rubro existente.
