# Casos de uso
## 1. Comprobante de venta

Permite consultar los datos de una compra realizada, mostrando la fecha, los datos del cliente, el método de pago, los productos comprados, las cantidades, los precios y el total de la compra.

## 2. Informe de ventas

Permite analizar las ventas realizadas durante un período determinado, agrupándolas por categoría. Muestra el total vendido, las unidades vendidas y la cantidad de compras por categoría.

## 3. Consulta avanzada de productos más vendidos

Permite identificar los productos de los que se vendieron más de una unidad durante un período determinado. Muestra el nombre del producto, su categoría, las unidades vendidas y el importe total vendido.

## Objetivo

Estas consultas permiten obtener información útil para controlar las ventas, consultar operaciones realizadas y conocer qué productos tienen mayor movimiento.
