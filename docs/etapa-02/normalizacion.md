# Normalización 3FN
En nuestra tablas nos aseguramos de eliminar todas las dependencias transitivas, asi ningun atributo depende de otro que no sea la clave primaria, un buen ejemplo  de esto dentro de mi modelo es la tabla PRODUCTO, donde guardo el id_categoria y el cod_Proveedor exclusivamente como Claves Foraneas, de esta manera si un proveedor cambia su razon social o una categoria cambia de nombre, la actualización se realiza unicamente en su tabla de origen, asi la tabla de productos queda intacta y se evita cualquier redundancia en la base de datos.
