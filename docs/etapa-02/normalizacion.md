# Normalización 3FN
En nuestra tablas nos aseguramos de eliminar todas las dependencias transitivas, así ningún atributo depende de otro que no sea la clave primaria, un buen ejemplo de esto dentro del modelo es la tabla PRODUCTO, donde se guarda el id_categoría y el cod_Proveedor exclusivamente como Claves Foráneas, de esta manera si un proveedor cambia su razón social o una categoría cambia de nombre, la actualización se realiza unicamente en su tabla de origen, así la tabla de productos queda intacta y se evita cualquier redundancia en la base de datos.
